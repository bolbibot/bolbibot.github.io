# Бот-загрузчик видео

Telegram-бот: человек присылает ссылку на видео, выбирает качество и
получает файл. Одно скачивание в сутки бесплатно, дальше — пакеты за
звёзды Telegram и (по желанию) за рубли через Robokassa.

Поддерживаются YouTube, VK Видео, Rutube, TikTok, Дзен, Одноклассники,
Twitch, Vimeo, Dailymotion. Список меняется переменной `ALLOWED_HOSTS`.

## Что нужно подготовить

1. **Бот.** В [@BotFather](https://t.me/BotFather): `/newbot`, сохраните
   токен. Оплата звёздами включена у всех ботов, отдельно подключать
   ничего не нужно.
2. **`api_id` и `api_hash`.** На <https://my.telegram.org> → API
   development tools. Нужны, чтобы отправлять файлы до 2 ГБ.
3. **Сервер.** VPS за пределами России (YouTube из России замедлен),
   от 2 ГБ памяти и 40 ГБ диска, с установленным Docker.
4. **Ваш Telegram ID** — подскажет [@userinfobot](https://t.me/userinfobot).

## Запуск

```bash
git clone https://github.com/bolbibot/bolbibot.github.io.git
cd bolbibot.github.io/downloader-bot
cp .env.example .env
nano .env            # заполните BOT_TOKEN, TELEGRAM_API_ID, TELEGRAM_API_HASH, ADMIN_IDS
docker compose up -d --build
docker compose logs -f bot
```

Если бот раньше работал через обычный Bot API, один раз «отвяжите» его,
иначе свой сервер его не увидит:

```bash
curl "https://api.telegram.org/bot<ТОКЕН>/logOut"
```

Обновление: `git pull && docker compose up -d --build`.
База лежит в `data/bot.db` — это единственное, что нужно сохранять.

## Цены и лимиты

Все значения в `.env`, после изменения: `docker compose up -d`.

| Переменная | По умолчанию | Что это |
|---|---|---|
| `FREE_PER_DAY` | 1 | бесплатных скачиваний в сутки (сброс в полночь по Москве) |
| `PRICE_P10_STARS` / `PRICE_P10_RUB` | 25 / 49 | 10 скачиваний |
| `PRICE_P50_STARS` / `PRICE_P50_RUB` | 100 / 199 | 50 скачиваний |
| `PRICE_UNLIM30_STARS` / `PRICE_UNLIM30_RUB` | 150 / 299 | безлимит на 30 дней |
| `MAX_DURATION` | 10800 | максимальная длина ролика, секунды |
| `PARALLEL` | 3 | сколько видео скачивается одновременно |

Скачивание списывается только после того, как файл пришёл в чат.
Тексты сообщений — в `bot/texts.py`.

## Если YouTube не отдаёт видео

С адресов дата-центров YouTube часто отвечает «подтвердите, что вы не
бот». Бот в этом случае пишет человеку, что сайт не отдаёт видео, и
ничего не списывает. Варианты:

- `PROXY_YOUTUBE` — резидентный прокси только для YouTube;
- `YOUTUBE_COOKIES` — файл cookies отдельного (не личного!) аккаунта
  YouTube в формате Netscape, положите его в `data/` и укажите путь
  `/app/data/youtube.txt`.

Для российских сайтов, которые не открываются из-за границы, задайте
`PROXY_VK`, `PROXY_RUTUBE`, `PROXY_DZEN`, `PROXY_OK`.

## Обязательная подписка на канал

Укажите `REQUIRED_CHANNEL=@вашканал` и добавьте бота администратором
канала. Проверка действует только на бесплатные скачивания.

## Оплата картой (Robokassa)

**Важно:** правила Telegram требуют продавать цифровые услуги в ботах
только за звёзды. Кнопка оплаты картой — риск: бота могут ограничить.
Поэтому Robokassa по умолчанию выключена.

1. Зарегистрируйте магазин в Robokassa (нужна самозанятость или ИП).
2. Направьте домен на сервер (A-запись).
3. В настройках магазина:
   - Result URL: `https://ВАШ_ДОМЕН/robokassa/result`, метод **POST**;
   - алгоритм расчёта хеша — тот же, что в `ROBOKASSA_ALGO`;
   - запишите пароль №1 и пароль №2.
4. В `.env`: `ROBOKASSA_ENABLED=1`, `ROBOKASSA_LOGIN`, `ROBOKASSA_PASS1`,
   `ROBOKASSA_PASS2`, `DOMAIN`. Для проверки — `ROBOKASSA_TEST=1` и
   тестовые пароли.
5. Запуск вместе с HTTPS-сервером:
   `docker compose --profile robokassa up -d --build`.

Если магазин обязан выдавать чеки, включите `ROBOKASSA_RECEIPT=1`;
ставка налога в чеке — «без НДС». Формат чека проверьте тестовым
платежом: он не был проверен на настоящем магазине.

## Команды администратора

- `/stats` — пользователи, скачивания, выручка.
- `/refund НОМЕР_ЗАКАЗА` — возврат. Звёзды возвращаются автоматически;
  для оплаты картой бот снимает начисление, деньги возвращаются вручную
  в кабинете Robokassa.
- `/block ID` и `/unblock ID` — закрыть или вернуть доступ человеку.
- `/block ССЫЛКА` и `/unblock ССЫЛКА` — запретить видео (например, по
  жалобе правообладателя).

Номера заказов и ID покупателей видны в базе:
`sqlite3 data/bot.db "SELECT id,user_id,tariff,method,amount,status FROM orders ORDER BY id DESC LIMIT 20"`.

## Вывод звёзд

Звёзды копятся на балансе бота. Вывод — в настройках бота в Telegram
(«Баланс»), через Fragment в TON; дальше TON продаётся за рубли.
Минимум и срок удержания смотрите там же.

## Список приёмки после запуска

Эти пункты нельзя было проверить без настоящего бота и сервера.

- [ ] `/start` показывает приветствие и кнопку BolBiBot.
- [ ] Ссылка на Rutube: приходят кнопки качества, затем видео.
- [ ] То же для YouTube, VK и TikTok (YouTube может потребовать прокси).
- [ ] «Только звук» присылает MP3.
- [ ] Вторая ссылка в тот же день показывает тарифы, а не скачивает.
- [ ] Покупка «10 скачиваний» за звёзды: баланс в `/balance` вырос на 10.
- [ ] `/refund` этого заказа: звёзды вернулись, баланс уменьшился.
- [ ] Ролик больше 50 МБ приходит (проверка своего сервера Bot API).
- [ ] Повторная ссылка на уже скачанный ролик приходит мгновенно.
- [ ] Ссылка на плейлист, трансляцию и неизвестный сайт даёт понятный отказ.
- [ ] Robokassa (если включена): тестовый платёж зачисляется, в кабинете
      у уведомления статус «успешно»; повторная отправка уведомления из
      кабинета не добавляет скачивания второй раз.
